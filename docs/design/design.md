# 视觉系统

## 视觉方向

终末地工业 HUD 风格的数据分析界面：深色碳黑底、米白信息文字、黄绿色状态高亮，搭配细线框、技术标记和克制的胶囊形状态组件。视觉装饰服务于定位和状态反馈，不遮挡统计内容。

## 字体与尺寸

- 标题优先使用 Barlow Condensed。
- 正文、表格和数据使用 Inter；中文使用可用的系统中文字体回退。
- 普通控件使用 2–4px 圆角；状态胶囊可以使用完整圆角，卡片保留 1px 细线框和轻微切角感。
- 页面保持 1440px 左右最大宽度，窄窗口转为单列。

## 状态规则

- 成功、失败、警告和进行中必须有文字或图标辅助颜色。
- 空态必须解释原因并给出下一步动作。
- 错误态必须说明原因并提供重试或排查方向。
- 图表必须有标题、单位、图例和无数据处理。

## 操作控件

- 统一按钮样式由 `web/src/endfield.css` 管理，在业务布局样式之后加载；页面使用 `ef-button` 和明确的变体，避免按所有 `button` 重设样式。
- 每个操作区域最多一个实心主按钮：全局解析入口、解析页开始解析。常用回放/收藏动作使用黄绿色细线 `ef-button--accent`；导入、导出、返回、重试使用中性细线按钮。
- 删除和清空使用 `ef-button--danger`：默认中性文字和透明背景，悬停或键盘聚焦时显示红色细线与文字；保留图标、文案和原有确认流程。
- 控件高度默认 34px，图标 14px，边框 1px，圆角 2px；回放页保留既定控件宽高与窗口缩放规则。
- 悬停只改变边框与底色，不移动布局；键盘聚焦使用清晰轮廓，禁用态取消强调并保留文字可读性。取消常驻导航图标脉冲和卡片浮动。
- 背景采用低对比细网格，侧栏和数据卡统一碳黑色；胜负、CT/T 等业务颜色保持语义，不能用品牌色覆盖阵营。

新页面优先引用已有 Token 和组件，不直接创造新的品牌色、字号体系、圆角体系或阴影体系。
