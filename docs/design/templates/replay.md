# 回放页模板

1. 单一回放操作栏：标题、地图/回合、已选玩家、收藏当前回合与返回比赛记录
2. 个人收藏夹只使用全局导航入口，不在回放页重复渲染收藏列表或浮层
3. 2D 地图与队伍面板保持完整尺寸；已录制 POV 固定在地图左侧的可滚动轨道
4. 独立进度条区域，包含播放、下一回合、回合跳转和拖动进度

进度条区域的左边界对齐 POV 卡片，右边界对齐地图卡片；宽度和居中规则必须与上方卡片容器一致。窄窗口按纵向布局展示，进度条保持在卡片下方。

POV 轨道位于地图左侧，与地图上边界对齐；桌面轨道宽 270px，完整画面单列排列，内容不足时高度随内容收缩，超出地图高度时轨道自身滚动。每个视频保持完整 16:9 画面，使用 contain，禁止 cover 裁切。点击画面或 Enter/空格打开大视角，玩家名称放在底部渐变遮罩中，不再设置独立放大按钮或重复的原生控制条。播放和进度由公共时间轴及大视角原生控件统一控制；窄窗口轨道放在地图下方，可以使用双列。没有 POV 时使用紧凑空态，不留整屏空白。

2D 地图标记按真实 SteamID 关联 POV，不用昵称或猜测槽位。普通地图只播放第一个 POV 的声音，打开大视角后只播放该视角；返回地图恢复第一个 POV。静音视角继续共用时间轴播放和跳转。原生视频全屏也应切换唯一音源；退出全屏恢复当前大视角或第一个 POV。

## 收藏操作栏

- 操作栏与 POV/地图/时间轴的外边界对齐。标题、当前地图/回合、选择状态和操作按钮分区清晰，不使用另一张大卡片承载按钮，不以绝对定位摆放控件。
- 已选人数和玩家名称在独立的固定高度区域显示，长名称省略并可悬停查看；提供清空选择的图标按钮。零选择、加载、保存失败和已收藏有明确状态。
- 玩家卡片整张可点击选择 POV，不显示原生勾选框。选中使用独立品牌色高亮框及紧凑 POV 标记，保留阵营色侧边与存活/阵亡状态；再次点击取消。支持 Tab 聚焦、Enter/空格切换及无障碍选中状态，选择前后卡片尺寸不变。
- 收藏唯一性由比赛 ID、回合和无序 SteamID 集合决定。相同选择再次保存不添加重复项，也不覆盖已有备注；不同玩家组合仍可分别收藏。保存成功后按钮显示“已收藏”。历史收藏不自动删除。
- 收藏与返回按钮带现有图标，按钮尺寸保持稳定；窄窗口仅操作栏分行，不能溢出或遮挡地图。Electron 整体缩放及地图/队伍/时间轴的布局规则保持不变。

回合胜方色块使用后端返回的该回合获胜阵营 `scoreTimeline[].side`：CT 胜蓝色、T 胜黄色，缺失为未记录。切换常规半场或加时半场后，全部回合的胜方颜色、悬停文字与无障碍标签保持一致；当前选中回合只改变选中高亮。实时地图与玩家卡片仍按当前回合的阵营着色。

地图保持 1:1，不通过拉伸地图调整模块宽度。布局修改保留加载、无数据、失败状态和所有回放操作，不改变后端 tick、身份或队伍语义。

切换回合的加载提示放在地图现有倒计时位置，不再在地图上方插入加载条；错误提示使用固定高度状态区。加载前后地图、玩家面板、POV 和时间轴的几何位置保持不变。等待新回合数据时暂停公共时钟推进，不显示旧回合的倒计时。冻结结束可等于回合起点，缺失阶段事件显示「回合进行中」，不能虚构 15 秒购买阶段。

播放控件仅在首次加载或切换回合时禁用上一/下一回合；每 250ms 更新位置快照不能改变按钮禁用状态、透明度或播放图标。按钮按真实播放/回合状态更新，时钟独立刷新，不把实时 tick 绑定到控件视觉更新。

## POV 时间同步

- 进入回合后完整缓存该回合已录制的 POV，视频卡片显示缓存中、已缓存或失败重试状态；切换回合/离开页面取消旧下载并释放缓存。读取与解码复用同一视频元素，放大与切换视角不重新下载。
- 单击地图玩家、玩家卡片或进入 POV 后，时间轴切换为对应 SteamID 的个人事件；收藏的多人选择仍独立保留。个人事件包含自己的投掷、安装/拆弹、击杀与死亡，击杀与死亡有不同图标、颜色和文字提示。返回 2D 地图恢复全局事件；点击地图或页面空白区域退出玩家视角并恢复全局事件；不显示玩家事件说明行或击杀/死亡图例。
- 点击任意时间轴事件跳到事件发生前 3 秒，最早为本回合起点；提示仍显示事件真实时间。手动拖动进度条保持准确目标，不提前。
- 视频接口支持完整读取与标准字节范围读取；新录制视频每秒至少一个关键帧，便于拖动定位。缓存完成不代表所有帧已经解码，播放仍按视频真实时间同步。

- 点击 POV 只在原地图回放区域内显示大视角，保留左侧 POV 轨道、页面操作栏及底部公共时间轴；不得用固定全窗口遮罩代替区域内放大。仅显式点击全屏按钮才进入全屏。切换视角保持页面与左侧轨道的滚动位置，不调用自动滚动。

- 同回合各玩家从相同 start tick 录到相同 capture end tick。存活时锁定本人第一人称；死亡后镜头固定在本人的死亡地点，继续录制，不自动观战其他玩家。
- 视频时间零点对应回合起点，不以文件时长反推延迟。旧的死亡截短视频从零点播放，结束后保持末帧，不暂停其他 POV 或公共回放时钟。大视角和缩略视频强制同步暂停、播放与跳转，任何一个原生控件的传输操作都会同步到全部视角。

## 战术地图绘制

- 雷达只使用游戏 `panorama/images/overheadmaps/*_radar_psd.vtex_c` 转换的真实 1024px 方形底图；`maps/` 的地图徽章仅用于列表图标，不得复制到 `maps/radar/`。新增资源需核对 `resource/overviews/` 的坐标原点与 scale，缺少校准时不回退 Mirage 参数。底图加载失败或尺寸错误显示明确状态，不在错误底图上绘制玩家。
- 当前多层地图使用默认层；本次资源修复不冒充支持自动上下层切换，新增层选择必须单独设计和验收。

- 保留原雷达底图的坐标范围和方向，叠加米白细线轮廓；A/B 包点依据对应底图区域使用黄色高亮与字母标识。
- 玩家使用蓝/黄水滴标记。编号按本场队伍及 SteamID 固定为 1–9、0，与左右玩家卡片同步，切回合、交换阵营和阵亡后均不重新编号。
- 水滴尖端随 yaw 转动，编号始终正向可读。阵亡标记弱化并显示叉号；选中与悬停标记有独立轮廓。
- 地图默认只展示编号，悬停显示昵称、血量或未知状态，避免出生点昵称堆叠。原有烟雾、燃烧、闪光和炸弹保留。
- 此修改仅调整地图绘制与卡片编号，不改变页面模块位置、tick、统计和 Electron 整体缩放规则。

玩家面板由固定高度的队伍标题和五个等高卡片组成。每张卡片为昵称/经济、武器/KDA、血量/护甲、道具和血条分别预留独立空间；空道具栏也保留高度。长昵称单行省略，悬停可查看全名，不能挤压经济或换行撑高卡片。拾取、丢弃、切枪、阵亡和跨回合更新时，各分区、后续玩家、地图和进度条的位置不变。窄窗口地图与两队面板分行展示，道具图标不得换行或溢出卡片。

## 转播卡片与事件动画

- 击杀/死亡数字与编号身份牌使用独立网格列，身份牌不得旋转越界或覆盖统计；昵称与卡片外部尺寸保持不变。
- 打开的 POV 在左上方悬浮无边框同步的 1:1 战术小地图，桌面宽约 150–190px，避开右上角关闭按钮和底部视频进度条。显示同一时刻的玩家编号和阵营，当前视角有轮廓；按真实 SteamID 点击有录制的玩家可切换 POV，并保留播放/暂停、时间位置及唯一音源。缺少 POV 时保持原视角。
- POV 全屏以包含视频和小地图的容器进入，支持退出按钮与 Esc。小地图随容器缩放，在窄屏缩至 140–200px；雷达资源缺失显示状态。保留视频播放、暂停、音量与拖动控件。
- 全屏内切换玩家视角复用同一全屏容器，保持全屏、时间位置、播放状态与唯一音源；只有退出全屏、Esc 或关闭视频才退出。
- 小地图不显示顶部标题或操作提示行；全屏时仍显示并支持玩家视角切换。投掷物轨迹、烟雾、燃烧、炸弹及开枪效果与主地图共用事件和 tick 绘制，缺少真实事件时不虚构轨迹。

- 卡片采用阵营色侧边、大号血量、武器剪影和固定道具槽的转播 HUD。头像区域以地图编号作为身份牌，悬停显示 SteamID；不生成虚构玩家照片。昵称、经济、击杀/死亡/助攻与护甲仍可读取，未知值显示破折号。
- 保留队伍面板、五个等高卡片、地图与进度条的位置和整体缩放规则。阵亡显示文字与弱化样式，选中 POV 有边框反馈。
- 地图上的手雷、闪光、烟雾、燃烧弹与 C4 使用 CS2 的 Panorama 彩色物品图，不使用自绘罐体。按原图透明边界裁取显示区域、保留原色；加载失败回退到游戏 HUD 剪影。效果范围保留，剩余秒数放在紧凑图标容器内。
- 玩家圆形主体半径为 8–10px，道具计时容器直径为 28px（C4 为 32px），飞行道具高度为 11px；尺寸为整体缩放前的页面像素。水滴尖端与枪口提示同步缩短，减少重叠而不缩小实际效果范围。
- 投掷轨迹仅使用 Demo 中实际记录的弹体坐标，包含真实弹跳折线。只显示当前播放时刻之前的短尾迹与移动图标；没有轨迹数据时保留落点效果，不用投掷者与落点连线假冒轨迹。
- 开枪提示仅由 weapon_fire 事件驱动，使用短暂枪口闪光与朝向提示，不虚构命中位置或伤害。所有动画按回放 tick 推进，暂停冻结，拖动/切回合立即重算。
- 旧 Demo 可补采回放视觉事件，补采不更改比分、队伍与正式统计。无相应事件时提示数据缺项。

回放操作栏的收藏和返回使用同一中性细线按钮样式（132×36px）；清空选择为 36×36px 同风格图标按钮，危险悬停和禁用状态保留。

主地图不显示 PLAYER FOR POV 等装饰性英文操作提示，保留玩家卡片与地图的选择交互。
