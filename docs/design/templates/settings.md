# 设置页模板

1. 页面标题、版本与本地运行模式。
2. 录制环境：CS2、HLAE（包含 Source2 hook）、FFmpeg 和 FFprobe 的实际检测结果、路径与失败原因；提供重新检测。
3. 缺少 HLAE/FFmpeg 时，可在线下载补全或选择本机完整工具；FFmpeg 补全同时提供 FFprobe。下载、解压、验证、成功与失败有文字反馈，失败可重试并提供 GitHub 来源链接。
4. 录制画面选项；更改后在下一次任务生效。
   处理速度支持 1×、2×、4×（测试）；成片时间按真实 tick 区间校正。码率表示最终视频目标码率，支持自动及 8/12/20/30/50 Mbps，越高文件越大；不影响既有视频。
5. 独立的数据管理区域，清空保留确认流程。
6. 自定义 CFG：固定打开 data/recording.cfg，不允许前端传入任意路径。首次创建示例文件，保留已有内容；保存后下一次录制在隔离 profile 加载，覆盖界面视觉默认值。隐藏模型和仅显示击杀播报改由 CFG 控制，不再提供独立开关。
7. 项目与作者：显示 CS2 Cam、B 站真实头像/昵称、B 站主页、作者 GitHub 主页；外链在系统浏览器打开，头像失败有文字回退。
8. 版本更新：启动后默认自动检查 GitHub 稳定 Release，支持关闭自动检查、手动重试。展示当前/最新版本、下载进度、校验/安装状态和明确错误。只有用户点击“下载并安装”才更新；更新前要求解析/录制空闲，SHA-256 校验后退出安装并重启，保留 data 和旧版本备份。浏览器模式禁用本地更新操作。

- 工具按紧凑行排列，状态不能仅用圆点颜色表达；长路径换行，窄窗口操作换行。
- 浏览器模式明确提示需使用便携桌面端，禁用本地文件与下载操作。
- 缺少录制工具不影响统计、2D 回放与已有 POV。检测工具就绪不代表 Steam 已启动或当前没有普通 CS2，保留录制前说明。
- 在线补全保存在 data/tools，保留许可证；采用独立版本目录，验证通过后才保存路径。已有工具与用户数据不被覆盖。
