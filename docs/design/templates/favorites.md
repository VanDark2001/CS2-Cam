# POV 录制模板

导航入口与页面标题显示「POV 录制」，保留收藏数据和既有导入、导出、录制语义。比赛标题与收藏名称编辑使用短暂淡入淡出过渡，输入框自动聚焦；尊重系统减少动态效果设置。

1. 紧凑页面标题、收藏数量和导入比赛包入口。
2. 比赛索引：地图图标、中文地图名、比赛时间、收藏数量和本机比赛编号。
3. 当前比赛：地图/比分/时间，导出比赛包与进入比赛的操作。
4. 回合条目：地图与回合、玩家、备注、打开/生成 POV/删除收藏。

- 标题使用正常文档流，高度自适应，不继承全局页头的固定高度。页面区块不做浮动大卡片。
- 地图名和时间直接可见，不展示本地绝对路径作为主要信息。时间源优先比赛记录，历史收藏缺失时从真实比赛列表补齐；只有导入时间时明确标为导入时间，缺失显示时间未知，不把收藏时间当比赛时间。
- 备注未编辑时显示文本，编辑时才显示输入框；长昵称与长备注可换行，不挤压动作。移动窗口索引和内容纵向排列。
- 导出收藏以当前比赛为单位，携带已解析比赛数据、该比赛收藏条目的名称/备注/玩家，以及这些收藏回合与 SteamID 对应的已完成 POV。不得附带其他回合、其他玩家的视频或原始 Demo。未生成视角显示缺失数量，不伪装为已包含。
- 收藏名称可与备注一起编辑并随包导入；默认名称为中文地图与回合。已生成 POV 显示齐全或部分完成数量，齐全保留重新生成入口但必须二次确认，部分完成默认只生成缺失玩家。检查失败提供重试，不将失败当作未生成。
- 打包、上传、校验、导入、完成、失败有明确状态和可恢复入口。导出通过下载文件链接完成，不把大视频加载到前端内存。
- 导入不执行包内脚本/SQL，不使用包内绝对路径；校验格式版本、文件摘要和安全相对路径。数据库写入事务化并重映射 ID；重复比赛不覆盖已有统计，已导入视频不重复复制，收藏按比赛/回合/SteamID 集合合并并保留已有备注。
- 比赛页也提供导入和当前比赛导出入口；时间完整显示到分钟，未知/导入时间与真实比赛时间区分。
