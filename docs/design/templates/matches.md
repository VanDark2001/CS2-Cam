# 比赛页模板

比赛标题进入编辑与保存/取消返回时使用共享的短暂淡入淡出过渡，编辑输入框自动聚焦；尊重系统减少动态效果设置。

1. 页面标题、比赛筛选和解析入口
2. 比赛列表：时间、地图、比分、双方队伍、状态
3. 比赛详情：比分和阵容
4. 玩家数据：K/A/D、ADR、Rating、WE
5. 回合时间线
6. 高光、残局和武器分析

桌面端允许并排展示比较内容；窄窗口改为纵向区块。列表和详情必须保持明确的返回路径。

比赛标题与比分作为信息主体；标题下的单行工具栏依次提供回放、比赛包导入/导出和靠右的删除操作。包状态独立位于工具栏下方，不能挤压主操作或比赛标题。窄窗口允许操作自然换行。统计标签使用真实按钮，提供键盘聚焦和选中状态。

列表时间独立显示到分钟；来源为导入时间时明确标注，不为空白。比赛操作提供导出比赛包与导入比赛包，状态在原页面呈现。比赛包与收藏页共用流程，导入完成刷新真实 SQLite 数据并进入导入的比赛。

比赛页「导出整场比赛」包含完整已解析数据、本场收藏名称/备注和整场全部已完成 POV，不包含原 Demo。收藏页「导出本场收藏」仅附带该比赛已收藏回合/玩家的已完成视角，两类出口明确命名。已有可下载包保留导出按钮，重复相同范围时二次确认；取消可沿用下载链接，新增 POV 或收藏修改后重新准备包。

比赛详情的回放、导入、导出按钮统一为 132×36px 中性细线控件。高光与残局卡片保留回合、玩家及击杀/残局数，移除重复的结果副文案；整张卡片是可键盘访问的链接，进入本场对应正式回合的 2D 回放。
