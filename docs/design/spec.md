# 产品与页面功能规格

## 产品目标

CS2 Demo Show 将本地 Counter-Strike 2 Demo 转换为可追溯的比赛、玩家和战术数据，帮助用户复盘比赛、比较玩家表现和发现地图、武器及残局规律。

## 页面任务

- 比赛页：找到比赛、查看比分、阵容、回合、高光、残局和武器统计。
- 玩家页：按 SteamID 聚合玩家表现并支持进入个人主页。
- 个人主页：解释玩家长期表现、阵营差异、地图、武器、队友和残局能力。
- 地图/武器页：跨比赛比较地图和武器表现。
- 统计页：查看数据集的全局规模和关键指标。
- 解析页：上传 Demo、管理队列、观察进度并处理失败。
- 设置页：检测录制环境、补全 HLAE/FFmpeg/FFprobe、选择本地工具与调整录制选项，集中管理本地数据。

## 所有页面必须覆盖的状态

- 初始加载中
- 有数据
- 无数据
- 请求失败
- 数据不完整或某项无法计算
- 窄窗口响应式布局

## 解析任务状态

等待中、上传/解析中、成功、已跳过、失败。失败必须显示原因；已跳过必须说明重复或已存在。

## 通用验收标准

- 回放进入回合后完整缓存当前回合的 POV 并显示状态；跳转与视角切换复用缓存。玩家个人时间轴按 SteamID 筛选、包含击杀/死亡；返回地图恢复全局。事件点击提前 3 秒且不跨越回合起点，手动拖动保持原时间。

- 便携桌面版通过受限 preload 获取本次启动的本地 API 端口，不连接固定开发服务。页面结构、整体缩放和业务语义不变。
- 数据库、Demo、视频、收藏与录制配置位于便携版 data 目录。首次启动自动初始化，移动目录后仍可读取自有数据。
- POV 工具路径通过设置页或桌面原生菜单选择；设置页支持重新检测与在线补全 HLAE/FFmpeg（含 FFprobe）。缺少录制工具或 CS2/Steam 不影响统计与已有视频查看。退出遇到活动任务时提示等待或明确中断。

- 页面任务和主要下一步动作清楚可见。
- 关键统计与 `docs/STATISTICS_RULES.md` 一致。
- 空态、错误态和加载态不能被省略。
- 重要状态不能只用颜色表达。
- 桌面和窄窗口都能完成主要任务。
