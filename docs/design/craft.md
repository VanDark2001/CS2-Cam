# 视觉工艺与信息层级

## 整体气质

这是深色、专业、偏电竞的数据分析工具。参考终末地工业 HUD 的终端感：通过黄绿色状态线、技术编号、细线框和克制的网格纹理建立层次，视觉重点仍是清晰比较和快速定位异常。

## 信息层级

1. 页面标题和当前分析对象
2. 关键结论和核心指标
3. 趋势、比较和解释
4. 明细、原始记录和次要字段

## 数据密度

保持紧凑但可读。不要把每个字段都做成独立大卡片；表格适合大量可比较数据，卡片适合少量关键结论，图表适合趋势和比例。

## 排版

- 大数字只用于核心指标。
- 标题、指标、单位和辅助说明要有明显层级。
- 中文、英文和数字混排时保持稳定行高。
- 表格列名必须使用用户理解的业务名称。

## 动效

动效只服务于加载、进度、状态变化和操作反馈。使用短暂过渡，避免持续闪烁、无意义旋转或影响数据阅读的动画。页面标题、卡片标题和状态条可使用短小的英文技术标签，用于建立导航锚点，但不替代中文业务说明。

## 禁止事项

- 不堆叠同质卡片。
- 不随意增加渐变、紫色或与系统无关的装饰色。
- 不用颜色单独表达成功、失败或阵营。
- 不隐藏统计口径、数据范围和异常原因。
