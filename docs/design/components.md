# 组件语义边界

## 操作按钮

`ef-button` 是操作控件的共享样式：默认用于导入/导出/返回；`--primary` 用于开始解析；`--accent` 用于回放和收藏；`--quiet` 用于取消/编辑；`--danger` 用于删除/清空；`--icon` 必须提供可读的 aria-label。筛选列表、比赛标签、回合历史按钮不套用操作按钮，保留其选择或阵营语义。

## MetricCard

展示 ADR、Rating、WE、比赛场次等少量核心指标。不要用来承载长段解释或完整明细表。

## StatusBadge

表示运行中、成功、失败、已跳过、高危等明确状态。普通武器名称、地图名称和资源名称使用 Tag 或普通文本。

## TeamBadge

表示 A 组、B 组或明确的阵营信息。不能根据颜色自行推断队伍归属。

## Chart

用于趋势、比例和比较。必须处理加载、无数据和错误状态。

## EmptyState

用于没有数据的情况。说明为什么为空，并给出首个可执行动作。

## ErrorState

用于接口或数据处理失败。说明失败原因，并提供重试或排查方向。

## ParserProgress

只表示 Demo 任务状态：等待中、上传/解析中、成功、已跳过、失败。状态文案必须与后端结果一致。

## PlayerAvatar 与 MapIcon

头像或地图资源加载失败时必须有稳定的文字或默认图形回退，不能让布局塌陷。
